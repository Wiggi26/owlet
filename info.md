# Owlet Custom Integration

<!-- Installation instructions updated for source-based HACS downloads. -->

Add `https://github.com/Wiggi26/owlet` in **HACS → ⋮ → Custom repositories** with type **Integration**. Open **Owlet**, download, and restart Home Assistant. Before releases are published, select `main`.

For new installations, go to **Settings → Devices & services → Add integration → Owlet Smart Sock**. Existing installations keep their configuration entry when updating.

See the [README](README.md) for installation, updates, and troubleshooting.
